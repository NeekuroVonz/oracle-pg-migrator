Return a single JSON object only (no markdown, no prose):
{
  "sql": string | null,
  "status": "SUCCEEDED" | "FAILED" | "REVIEW_REQUIRED",
  "warnings": string[],
  "notes": string | null,
  "confidence": "low" | "medium" | "high"
}

Rules:
- Fix only what the compile error requires. Do not invent business logic.
- If you cannot fix the error with confidence, status is REVIEW_REQUIRED.
- Never include credentials, connection strings, tokens, or infrastructure secrets.
- You cannot mark an object VALIDATED. PostgreSQL compile is the technical judge.
- Return a full replacement SQL script, not a patch/diff.
